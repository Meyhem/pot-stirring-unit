# Stirrer – automatic pot stirrer (3D-printed)

DIY stirrer that stirs food in a pot on the stove. Nothing but the gearbox and
the stirring shaft sits above the food.

## The whole unit (top → bottom)
1. **Gearbox (top, above the pot)** – `angled_gearbox.scad`. Bevel gear pair in a
   split housing. Takes the tilted input rod and turns it into a vertical output shaft.
2. **Output shaft + paddle** – 6 mm stainless rod straight down into the pot, wooden
   paddle at the end (paddle not modelled yet).
3. **Input rod** – 6 mm steel rod running at 30° from vertical, from the motor up
   to the gearbox.
4. **Holding arm = spine** – wooden 20×40 mm arm standing on edge (40 mm in the shaft
   plane = the plane gravity bends it in), parallel to the input rod. Its near face is
   `arm_y0` = 31.5 mm from the rod axis (Ø55 drill head radius + 4 mm). A printed
   foot holds its bottom end on the board at 60°; the motor cradle and the gearbox
   both grip it with cheeks + wood screws → motor and gearbox aligned by construction.
   Not a printed part (plain wood), shown as a ghost in the assemblies.
5. **Motor mount (bottom, beside the pot)** – `motor_mount.scad`. Default = ONE print
   (user's choice): foot plate + arm cheeks + split ring around the TOPOWER 550-18V
   motor (RS-550, Ø38 mm body). Three-piece variant (foot, sliding cradle, 2 clamp
   caps) kept via `style="three_piece"`. In front of the can sits a **drill head**
   (from a cordless drill): beige planetary gearbox ~Ø44×40 with screw ribs, clutch
   collar Ø55×20 (thickest = `chuck_d`), keyless chuck ~Ø44×43 – lengths estimated
   from a photo, not measured (`head_*` params). The chuck grips the 6 mm input rod
   directly (no coupler). RS-550 vent slots are near the REAR end (~8–13 mm from
   the rear face) – keep them uncovered.

## Files
- `common.scad` – parameters shared by both models: `shaft_angle`, chuck, arm size +
  `arm_y0`, cheek thickness, wood screw pattern + `arm_screw_cut()`. Plain OpenSCAD.
  Change arm/chuck/angle ONLY here, then re-export both models.
- `angled_gearbox.scad` – parametric gearbox (current version: v4). Needs BOSL2 + common.scad.
- `motor_mount.scad` – one-piece motor mount (default) or three-piece variant.
  Plain OpenSCAD + common.scad.
- `stl/` – exported parts at default parameters: gearbox (housing_a/b, gear_in/out,
  spacer) and motor_mount_one_piece. Three-piece STLs were removed as obsolete
  (user's call 2026-11-25); export them on demand with `-D 'style="three_piece"'`.
  OpenSCAD re-exports can reorder triangles without changing geometry – don't commit
  an STL whose sorted vertices are unchanged.
- `stirrer.3mf` – old slicer project (2026-11-20), predates the arm/motor redesign.
  Re-slice from `stl/` before printing.
- `README.md` – public overview with images (GitHub landing page).
- `img/` – README images. All except `gear_boss.png` (carried over from the chat)
  are regenerated by `./render_images.sh`.
- `Makefile` – `make` (STLs), `check`, `prune`, `images`, `all-in`, `rebuild`.
- `tools/` – `check_stl.py` (mesh validity, any STL), `check_fit.py` (OpenSCAD
  fit checks), `stl_same.py` (geometry-equal test used by the Makefile). Stdlib only.
- `prompt_regenerate_gearbox.md` – short spec (Slovak) to regenerate the gearbox from scratch.

## Local environment
- OpenSCAD 2021.01 at `/usr/bin/openscad` (old but works with current BOSL2).
- BOSL2 cloned to `~/.local/share/OpenSCAD/libraries/BOSL2` (update: `git -C … pull`).
- Headless PNG renders need `xvfb-run -a openscad …` (STL export works without it).
- Render times are short: housing ~5 s, gears ~4 s.
- Write scratch renders/STLs outside the project (or to a temp dir), only final
  exports go to `stl/`.
- Git repo, branch `main`, remote `origin` = git@github.com:Meyhem/pot-stirring-unit.git.
  STLs and the .3mf are tracked as deliverables; scratch `preview.png` is ignored.
- **Keep README.md current:** on every change, update README.md text (specs, hardware,
  status checklist) and run `./render_images.sh` when geometry changed. Look at the
  new PNGs before committing. If you add a new part or file, add its image/camera to
  `render_images.sh` and a section to README.md.
- **After every iteration run `make all-in`** (= `make` + `make prune` + `make check`
  + `make images`) and fix anything that fails before committing:
  - `make` re-exports every printable part that changed (list in the Makefile:
    `GEARBOX_PARTS`, `MOUNT_PARTS`) with `--hardwarnings` + `Simple: yes` check. It
    keeps the old file when the geometry is unchanged (`tools/stl_same.py`: same
    vertex set + volume) – OpenSCAD re-exports reorder/re-triangulate otherwise.
  - `make prune` deletes STLs in `stl/` that aren't current parts → `stl/` = exactly
    what to print. New/renamed part → update the Makefile lists + rules.
  - `make check` = `tools/check_stl.py` (watertight, manifold, winding, volume,
    1 body, fits 220×220×250 bed; slivers from OpenSCAD's 6-digit output are only
    reported) + `tools/check_fit.py` (all fit checks must be EMPTY).
  - New fit check → add a branch to `gb_check()` / `mm_check()` in the model and a
    line to `CHECKS` in tools/check_fit.py.
  - `make images` re-renders README images; PNG re-renders of unchanged geometry are
    noise too – `git checkout` images whose part didn't change.
- **Auto-push:** after every iteration (each finished change: geometry edit + checks,
  STL re-export, README/images, doc update) commit and `git push` to `origin main`
  without asking.

## Gearbox (angled_gearbox.scad) – current design
- Straight bevel pair (BOSL2 `bevel_gear`, spiral=0), shaft angle 30° (input tilted
  30° from vertical), module 2, 15T pinion / 29T output gear (~1.93:1), backlash 0.2.
  Pitch dia 58 / 30 mm, pitch angles 19.87° / 10.13°.
- 6 mm steel shafts, each in two 626 bearings (6×19×6), 18 mm apart.
  Pockets Ø19.3 × 6.4 mm (`brg_clr`, `brg_hclr`) – 6.0 mm pockets were too tight in a real print.
  Pocket ledge touches only the bearing outer race.
- Gears: flat back (cone_backing=false), M3 grub screw + M3 nut trap from the back,
  hub boss Ø12 on the front face. Housing has a Ø14 pad opposite each boss with
  `axial_gap` = 0.3 mm → gears cannot slide into the walls (real prints stalled without this).
  A spacer (or M6 washers) between gear back and upper bearing stops the other direction.
- Tooth tip height above pitch base = face_width·cos(pitch_angle) + 1 (NOT sin –
  that bug once left 0.15 mm wall clearance). Cavity = that + gear_clear (2.5).
- Housing split in two halves in the plane of both shafts (x=0), joined by 6 M3
  bolts through a flange; flange is trimmed flush with the bearing-tube ends so
  shaft exits stay open. Print halves split-face down, supports on build plate only.
- Mounting: on the outer side of the input tube (away from the pot), arm near face
  at `arm_y0` (31.5) from the input axis. Arm 20 wide (`arm_w`, across) × 40 deep (`arm_t`, in the shaft plane) – on edge,
  because gravity bends it in the shaft plane. Not boxed in (user's call): each half
  has one flat cheek (`cheek_t` 6) against a side of the arm + a cap (`cap_t` 4) on
  top as end stop (weight goes into the arm end, not the screws). 2 countersunk
  4 mm wood screws per cheek, pattern `screw_pat` mirrored on side B so screws from
  both sides never meet. Cheeks need build-plate supports (they bridge the arm gap).
  No mounting on top of the housing (unreachable).
- `part` selects output: assembly, housing_a, housing_b, gear_out, gear_in, spacer, print_all.
- Coordinate frame: output axis = +Z through origin (pitch base at z=0, shaft goes
  down), input gear on +Y side; `in_frame()` maps children into the input-shaft frame.

## Motor mount (motor_mount.scad) – current design
- Modelled in the arm frame (common.scad): z = rod/motor axis up towards the gearbox,
  y = from the rod towards the arm, x across. `ARM()` maps it to the world (board top
  = z 0, arm near face meets the foot plate at the origin).
- **one_piece** (`part="mount"`, default): plate (half width `plate_hw1` 38, so the
  front board screws are clear of the ring for a vertical screwdriver) + cheeks
  running continuously from the plate to the ring's front end (4 wood screws per
  side = shared pattern applied to each half) + `ring_2d` profile: ring (`ring_t` 5,
  bore Ø38.4 via `ring_clr`) hulled up to the arm seat, pinch ears below. 3 mm slit
  at the bottom through wall and ears. The ring covers only the FRONT of the can
  (`ring_z0` 18 → 57, user's request: rear vents + end cap stay open for cooling).
  No rear lip (`lip_w` 0, optional): the drill gearbox housing (wider than the bore)
  sits against the ring's front face = the motor's axial stop. 2 M4 pinch bolts
  along x (counterbore +x, nut trap −x). Motor goes in from the front, rear first.
  Prints plate down, supports under the ring rear. ~76×166×113.
  Fit checks (all EMPTY): part ∩ motor cylinder Ø38, part ∩ drill head (Ø44 gearbox
  from z 57.01 + Ø55 collar), part ∩ arm
  (shrunk 0.01 – exact face contact at the seat otherwise reports a degenerate solid).
  Hard-code motor_z in check files – variables of a `use`d file are not visible.
- three_piece: Cradle: extruded profile, motor bore R, full width at the split line (M4 clamp
  bolts + side nut slots), narrowing to the arm seat at `arm_y0`, two cheeks up the
  arm sides with the shared screw pattern. 2 half-ring clamp caps under the motor,
  1.5 mm squeeze gap. Prints standing on its rear end face.
- Foot: plate (4 countersunk board screws) + two parallelogram cheeks = the arm's
  side silhouette up to `foot_len` 50. Arm end cut 30° off square, rests on the plate.
- `motor_z` (rear face position along the arm) is auto: lowest spot that keeps
  terminals/ring/ears `board_clear` (10) above the board (three_piece: also clear of
  the foot cheeks) → one_piece 45.9 mm (terminals are the limit), three_piece 52.
  Override with `motor_z_set`.
- `part`: assembly, mount, cradle, clamp, clamps_x2, foot, print_all (follows `style`). Echo reports chuck
  clearance, motor height above the board and where the chuck ends.

## Rendering / checks (run after every geometry change)
```bash
make all-in     # build changed STLs, prune, check (mesh + fit), render images
# scratch preview (headless) – write it outside the repo or as preview.png (ignored)
xvfb-run -a openscad -o preview.png --imgsize=1400,1100 --camera=0,35,-15,62,0,125,400 -D 'part="assembly"' angled_gearbox.scad
```
Fit checks (modules `gb_check` / `mm_check`, run by tools/check_fit.py, all EMPTY):
gear_vs_gear, housing_vs_gears, axial_stop_out/in (gear shifted axial_gap−0.05
towards the wall), mount_vs_motor, mount_vs_drill_head, mount_vs_arm (arm shrunk
0.01 – face contact at the seat), mount_vs_board. Known by hand: shifting a gear
0.4 mm → contact only within the boss radius (never teeth).
Motor mount: also read the echo (chuck clearance ≥ 4, lowest point ≥ board_clear)
and look at a side view (`--camera=0,-50,100,90,0,90,650`).
`use <file>` exposes modules/functions but not variables – put check logic in
modules inside the model, not in the check file.

## Constraints / preferences
- Materials: PETG / ASA / nylon, never PLA (heat + steam). Gears run dry, no grease (above food).
- Nothing greasy or wet-sensitive directly above the pot; lowest output bearing 626-2RS.
- Keep everything parametric; keep the BOM + assembly notes at the top of each .scad in sync.
